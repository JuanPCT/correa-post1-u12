# ADR-001 · Capas simples para reembolsos

Aceptada el 20 de noviembre de 2026.

La práctica requiere una base relacional. El equipo no tiene previsto sustituir el motor en los próximos tres años. Contabilidad sí prevé una API externa el próximo trimestre.

El servicio de aplicación usa directamente `RepositorioSolicitudesJpa`. La entidad conserva anotaciones de mapeo y el código de procesamiento recibe objetos de dominio y los pendientes ya cargados. Esto reduce interfaces y conversiones. Si se confirma un cambio de motor, habrá que extraer el puerto y adaptar las pruebas de integración.

`ObservadorCambioEstado` ya permite reemplazar la reacción de Contabilidad sin cambiar la aplicación ni los demás observadores. El envío de esta práctica es síncrono y ocurre después del commit. Si se exige entrega durable y reintentos, se reabrirá la decisión para evaluar una tabla outbox e idempotencia.
